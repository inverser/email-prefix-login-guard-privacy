Privacy Policy — Email Prefix Login Guard

Effective date: 18 August 2026

Email Prefix Login Guard is a browser extension whose single purpose is to prevent configured login attempts unless the username or email entered on the configured login page starts with an allowed prefix.

Data the extension handles

The extension may process the following information locally in the user's browser on websites for which the user or administrator has granted site access:

  • the username or email text entered in the configured login field;
  • the current website address/domain, so the extension can determine whether a configured rule applies; and
  • extension configuration such as the allowed prefix, protected website patterns, CSS selectors, strict-mode settings, and enabled/disabled state.

The extension is not designed to read or collect passwords, authentication cookies, payment information, browsing history, personal communications, or unrelated page content.

How the data is used

The username/email field value is checked locally against the configured prefix. The current website address is used locally to select the applicable rule. Configuration is stored locally using the browser's extension storage or, in managed environments, supplied through administrator-managed browser policy.

Data transmission, collection, and sharing

Email Prefix Login Guard does not send username/email values, form data, configured websites, or extension configuration to the extension developer or to any external server. The extension does not include analytics, advertising, telemetry, tracking pixels, or third-party data-collection SDKs.

The developer does not sell, rent, share, or transfer user data to advertisers, data brokers, or other third parties.

Data retention and deletion

Username/email values are evaluated transiently in the page and are not stored by the extension. Local configuration remains in browser extension storage until it is changed, removed, or the extension is uninstalled. Managed configuration is controlled by the user's organization or device administrator.

When a locally configured website rule is removed, the extension also requests removal of its optional host access for that website when that permission is no longer needed by another rule.

Permissions

  • storage — stores the allowed prefix and configured website rules locally, and reads administrator-managed configuration when present.
  • scripting — registers the packaged login-guard content script on websites that have been explicitly granted access.
  • optional website access — requested only for a website when the user chooses to add that website. The extension does not receive blanket website access at installation time.

Security

All executable code used by the extension is packaged with the extension. The extension does not download or execute remote code.

Limited Use

The extension uses data only to provide its disclosed single purpose: enforcing the configured username/email prefix on protected login pages. The use of information received from Google APIs, if any, will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes to this policy

If the extension's data practices materially change, this policy and the Chrome Web Store disclosures will be updated before the new practices are introduced.

Contact

For privacy questions, use the developer contact or support address shown on the extension's Chrome Web Store / Microsoft Edge Add-ons listing.
